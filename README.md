## 📖 Présentation

CookChef est une application développée dans le cadre de mon apprentissage de **React 19**.

L'objectif est de proposer une interface moderne permettant aux utilisateurs de rechercher facilement des recettes de cuisine, d'en consulter les informations détaillées et de sauvegarder leurs recettes favorites.

Ce projet m'a permis de mettre en pratique les principaux concepts de React moderne ainsi que l'utilisation de bibliothèques courantes de l'écosystème.

---

## ✨ Fonctionnalités

- 🔍 Recherche de recettes
- 📋 Affichage des résultats sous forme de cartes
- ❤️ Gestion des favoris
- 📄 Consultation du détail d'une recette
- ⚡ Chargement dynamique des données via API
- 📱 Interface responsive
- 🎨 Design moderne

## 🚀 Installation

Cloner le projet

```bash
git clone https://github.com/votre-utilisateur/cookchef.git
```

Entrer dans le dossier

```bash
cd cookchef
```

Installer les dépendances

```bash
pnpm install
```

Lancer le serveur de développement

```bash
pnpm dev
```

Construire la version de production

```bash
pnpm build
```

Prévisualiser la version de production

```bash
pnpm preview
```
